# Работа с Canvas

Canvas работает самостоятельно: для схем, подписей и рисунков не нужны Dataset. В новой пустой доске кнопка «Пример инфраструктуры» создаёт небольшую схему с двумя Frame, устройствами и коннекторами. Всё действие можно отменить одним Undo.

## Инструменты и навигация

- **V** — выделение. Тяните пустое место для рамки выделения; Shift добавляет объекты.
- **H** — рука; **Space** временно включает руку. Средняя кнопка мыши тоже перемещает доску.
- **S / T** — фигура / текст: выберите инструмент, затем место на доске. **C** — коннектор: нажмите первый и второй объект. Также можно соединять видимые боковые якоря перетаскиванием.
- **P / E** — перо / ластик. Ластик удаляет целый штрих, которого касается линия движения. Незавершённый жест отменяется через Esc, смену инструмента или потерю фокуса.
- **Esc** выходит из инструмента. Двойной клик по подписи открывает редактор; Esc отменяет текстовый черновик, Ctrl+Enter сохраняет. В однострочных заголовках достаточно Enter. Клик снаружи сохраняет правку. Горячие клавиши Canvas во время ввода отключены.
- Колесо меняет масштаб относительно курсора. Кнопка **«Тачпад»** переключает прокрутку на перемещение доски; pinch продолжает менять масштаб. Настройка сохраняется в этом браузере.
- **Ctrl+0** показывает всё, **Ctrl+1** возвращает 100%, **F** показывает выделение, **+ / −** меняют масштаб. Мини-карта поддерживает перемещение и масштабирование.

На macOS вместо Ctrl используйте Command. Справка открывается кнопкой «?» внизу или клавишей `?`.

## Объекты, группы и Frame

**Ctrl+C / V / D** копируют, вставляют и дублируют выделение. Внутренние коннекторы и вложенные объекты копируются с новыми ID. Родитель вне копируемого набора не наследуется. Правый клик на пустом месте позволяет вставить набор в выбранную точку.

**Ctrl+G** создаёт группу; **Ctrl+Shift+G** разбирает выбранную группу или Frame, сохраняя содержимое. «Во Frame» создаёт секцию вокруг выделения. Контейнеры имеют явный состав: случайно оказавшийся рядом или поверх них объект сам не прикрепляется.

Контейнер перемещается за заголовок вместе со всеми вложенными объектами. Resize **группы** масштабирует геометрию её содержимого; resize **Frame** меняет границу секции. «Прикрепить» помещает выделение в наименьший полностью окружающий Frame; «Отсоединить» сохраняет мировые координаты. Вложенные Frame поддерживаются; циклическое прикрепление запрещено. Delete удаляет контейнер с его содержимым и инцидентными коннекторами; если содержимое нужно сохранить, сначала разгруппируйте.

Маркеры размера меняют геометрию; Shift сохраняет пропорции. Alt временно отключает сетку и smart guides. Во время перемещения направляющие показывают совпадающие края и центры. В меню «Выровнять» доступны края, центры и равные промежутки; в «Слои» — порядок отрисовки. Ctrl+[ / ] перемещают на один слой, Ctrl+Shift+[ / ] — в начало/конец.

Круглый маркер над выделенным объектом вращает его вокруг центра; Shift задаёт шаг 15°. Точное значение задаётся в панели оформления. Поворот контейнера применяется также к позициям и углам его содержимого.

Панель оформления позволяет выбирать прямоугольник/эллипс/ромб, заливку, цвет линии и текста, размер текста и непрозрачность. Поле размера можно полностью очистить и ввести новое число; Enter или переход из поля подтверждает ввод, Esc возвращает значение до редактирования. Пустое поле при подтверждении сохраняет последний допустимый размер. У текста и стикера доступна автовысота. «Копировать стиль» / «Применить стиль» переносят оформление между объектами в этом браузере.

Штрих — отдельный объект: его можно выбирать, двигать, масштабировать, вращать, копировать, включать в группу, менять слой и удалять. Он также виден в панели объектов. Старые рисунки преобразуются без изменения точек и идентификаторов.

Выделенный коннектор имеет собственную панель подписи, прямого/изогнутого маршрута и стрелки. Коннекторы удаляются через Delete; удаление узла также удаляет его связи.

## Совместная работа и история

Owner и Editor изменяют Canvas. Viewer и Commenter могут выбирать объекты, пользоваться поиском, навигацией и копированием; запись документа блокируется сервером. Комментарии регулируются отдельной политикой роли.

Изменения независимых полей одного объекта (например, позиция и текст) объединяются Yjs. Одновременные изменения одного и того же поля разрешаются правилами CRDT; это не журнал альтернативных текстов. Undo/Redo относятся к локальным действиям и сохраняют независимые правки другого участника.

Статус `connected` означает соединение, `saving` — неподтверждённые изменения. При потере связи появляется предупреждение: оставьте вкладку открытой до восстановления. Изменения в отключённой вкладке синхронизируются после переподключения; закрытая до синхронизации вкладка не является сохранённой резервной копией. Проверяйте завершение сохранения перед перезагрузкой.

## Проверки для разработчика

```bash
npm install --package-lock=false
npm run typecheck
npm test
npm run build
# Нужен локальный PostgreSQL с DATABASE_URL либо значениями .env.example.
docker compose up -d postgres
npm run test:e2e
```

`test:e2e` подготавливает отсутствующую начальную схему и применяет миграции, затем использует существующий dev-сервер или запускает его сам. Существующие данные не очищаются; сценарии создают и удаляют только свои тестовые доски. Если Docker в облаке не читает исходный init.sql из-за прав checkout, используйте подготовленный Compose override из инструкций среды.

Playwright использует `/usr/bin/chromium`, если он установлен; иначе выполните `npx playwright install chromium`. Путь можно задать через `CHROMIUM_PATH`. В CI браузер устанавливается отдельным job. Скриншоты и трассы неудачных проверок лежат в `test-results/`.

Автоматизация проверяет события мыши, клавиатуры и колеса в Chromium. Она не заменяет проверку физических устройств, Safari/Firefox и пользовательскую приёмку удобства.

Горячие клавиши инструментов и истории работают по физическим клавишам при любой раскладке. Во время редактирования текста вводятся обычные символы. Редактор текста фигуры прозрачен и сохраняет её оформление; цветовые индикаторы на панели имеют фиксированную высоту. Инспектор обновляет содержимое при изменении свойств и не перерисовывает его из-за одних координат во время перемещения.

Рамка выделяет объекты без автоматического выбора их коннекторов и FK-связей. Панель оформления коннектора появляется при отдельном нажатии на линию, когда объекты не выделены. Копирование и удаление объектов по-прежнему учитывают их связи.
