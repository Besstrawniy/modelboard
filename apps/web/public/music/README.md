# Своя музыка

Положите MP3, OGG, WAV, M4A, AAC, FLAC или OPUS непосредственно в эту папку.
При `npm run dev` и `npm run build` каталог создаётся автоматически.
Если сервер уже запущен, выполните `npm run music:scan` и обновите доску.
Треки появятся в разделе «Музыка» → «Общий трек» → «Моя музыка».
Кнопки предыдущего/следующего трека переключают общий трек для участников.
Выбранный трек повторяется; прослушивание и громкость каждый включает у себя.
Добавляйте сюда только музыку, которую разрешено раздавать: содержимое `public`
доступно посетителям сайта. Аудиофайлы не нужно включать в Git.
